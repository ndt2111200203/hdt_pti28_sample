# HDT PTI28 Sample (SPCN)

Dự án mẫu lập trình ứng dụng quản lý xe (SPCN) bằng Python và PyQt6.

## Cấu trúc thư mục
- `data/`: Chứa cơ sở dữ liệu mẫu (`accounts.json`, `car.json`)
- `modules/`: Mã nguồn logic và xử lý sự kiện giao diện (`main.py`, `modules.py`, `data_io.py`)
- `ui/`: Các file thiết kế giao diện PyQt (`start.ui`, `main.ui`)

## Hướng dẫn chạy
1. Cài đặt các thư viện phụ thuộc:
   ```bash
   pip install PyQt6
   ```
2. Khởi chạy ứng dụng:
   ```bash
   python modules/main.py
   ```
